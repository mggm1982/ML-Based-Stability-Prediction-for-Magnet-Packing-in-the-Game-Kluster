# Reproduction Guide: Kluster Magnet-Stability

This document provides exact instructions to recreate the execution environments, run the physics test suite, regenerate each dataset, and reproduce the final experimental tables T1 through T5.

---

## 1. Environment Setup

### Tested Reproduction Environment (Python 3.13)
The project deliverables in `results/final/` were validated on Python 3.13.5 (Windows 11) using the dependencies pinned in `environment/requirements-tested.txt`:
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows (or `source .venv/bin/activate` on Unix)
pip install -r environment/requirements-tested.txt
```

### Original Environment (Python 3.12.8)
The original paper baseline was developed on Python 3.12.8 using the dependencies recorded in `environment/requirements-original.txt` (from `VERSIONS_USED.txt`):
```bash
py -3.12 -m venv .venv312
.venv312\Scripts\activate
pip install -r environment/requirements-original.txt
```

---

## 2. Running Physics Tests

Run the physics test suite:
```bash
python tests/test_physics.py
```
- If all 20 checks pass, the script prints `ALL TESTS PASSED` and exits with code `0`.
- If any check fails, it prints `SOME TESTS FAILED` and exits with code `1`.

Check exit code on Windows:
```cmd
cmd /v:on /c "python tests\test_physics.py & echo EXIT_CODE=!errorlevel!"
```

---

## 3. Regenerating Datasets

All datasets are generated by `scripts/make_dataset.py` using `src/kluster/generate.py`.

### 1. Default Physics Parameters (300 Games)
```bash
python scripts/make_dataset.py --games 300 --seed 2026 --out data/kluster_dataset.csv
```

### 2. Default Physics Parameters (1,000 Games)
```bash
python scripts/make_dataset.py --games 1000 --seed 2026 --out data/kluster_dataset_1000.csv
```

### 3. Randomized Physical Parameters (1,500 Games)
```bash
python scripts/make_dataset.py --games 1500 --seed 2027 --random-params --out data/kluster_dataset_v2.csv
```
*Note: Seed 2027 exactly reproduces the physical parameters ($\mu_s, \mu_k, k_{\text{scale}}$) stored in `data/kluster_dataset_v2.csv` across all games.*

## 4. Reproducing Final Tables T1..T5

### Quick Reproduction
Regenerates all final summary tables and figures from existing result outputs:
```bash
python scripts/reproduce_all.py
```

### Full End-to-End Rerun
Reruns all underlying simulation and calibration pipelines from raw datasets:
```bash
python scripts/reproduce_all.py --rerun
```

### Individual Experiment Pipelines
- **T1 & T2 (Mondrian Conformal Risk Control)**:
  ```bash
  python scripts/run_mondrian.py --repeats 100
  ```
- **T3 (Parameter Shift Experiments A, B, C)**:
  ```bash
  python scripts/run_paramshift.py --repeats 20
  ```
- **T4 (Calibration Size Scaling)**:
  ```bash
  python scripts/run_calsize.py --repeats 50
  ```
- **T5 (Neural Network Baseline)**:
  ```bash
  python scripts/run_nn.py --repeats 20
  ```
